# PHAS0097 Example scripts
This repository contains the scripts run for the across track interpolation described in my Master's project, "Interpolating Sea Level Anomaly Using State-of-the-Art AI Algorithms". Since the specific data used are not publicly available they are not provided here or linked to. However, these scripts will work with any prepared data in the same structure as the provided CSV file.
To execute the GPSat interpolation, please install GPSat and configure the necessary Python environment using the documentation:

[https://github.com/CPOMUCL/GPSat](https://github.com/CPOMUCL/GPSat)

You will then be able to call the functions found in `gpsat_ex_github.ipynb`.

Please do the same with the DRF documentation to execute the DRF interpolation:

[https://github.com/totony4real/DeepRandomFeatures](https://github.com/totony4real/DeepRandomFeatures)

And use the file `drf_ex_github.ipynb` with `config_demo8.yaml`.
